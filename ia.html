En 3ème année, lorsque nous sommes en formation initiale, nous devons une réalisé une SAE qui se déroule sur plusieurs mois. C'est ainsi qu'en groupe de 7 étudiants, nous travaillons sur un projet qui concerne l'IA, plus précisement l'apprentissage par renforcement. Personnellement, sur le projet j'ai appris à utiliser Gymnasium, une API pour l'apprentissage per renforcement en python, puis j'ai codé des programmes pouvant calculer un MRP (Processus de Récompense de Markov) et un MDP (Processus de Décision de Markov). Enfin j'ai complété un rapport à l'aide de mon groupe qui pourra être potentiellement utilisé dans les prochaines années pour les nouveaux étudiants

Voici un extrait de code (en python) illustrant l'implémentation des équations de Bellman : 


import numpy as np

# --- FORMULE : V = (I - gamma * P)^-1 * R ---
# p : matrice de transition
# r : récompenses immédiates
# i : matrice identité
def bellman_vector_form(p, r, gamma):
    i = np.eye(len(p))
    # Résolution matricielle
    v = np.linalg.inv(i - gamma * p).dot(r)
    return v

# --- FORMULE : V(s) = R(s) + gamma * Σ(P(s,s') * V(s')) ---
def bellman_recursive_form(p, r, gamma):
    v = np.zeros_like(r)
    convergence = 0.0000001

    # Itération jusqu'à convergence
    for _ in range(10000):
        v2 = r + gamma * p.dot(v)
        if np.max(np.abs(v2 - v)) < convergence:
            break
        v = v2
    return v

# --- JEU DE DONNÉES TEST ---
P = np.array([[0.7, 0.3],
              [0.4, 0.6]])
R = np.array([5.0, 10.0]) # Flottants pour éviter les erreurs de type
gamma = 0.9

# Exécution
V_vec = bellman_vector_form(P, R, gamma)
print(f"V (Vectoriel) = {V_vec}")

V_rec = bellman_recursive_form(P, R, gamma)
print(f"V (Récursif)  = {V_rec}")
